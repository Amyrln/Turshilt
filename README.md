# Халдун — туршилтын хувилбар

👉 **https://amyrln.github.io/Turshilt/**

Халдуныг бүртгүүлэхгүйгээр, жишээ өгөгдлөөр туршиж үзэх хуудас.
- Нээгдэнгүүт туршилтын горимд шууд орно. Юу ч хадгалагдахгүй.
- Бүх item, 13-р зууны аяллын 4 бүлэг, «Миний нутаг» 3D тоглоом нээлттэй.

3D загварууд нь үндсэн сайтын ([Amyrln/khaldun](https://github.com/Amyrln/khaldun)) `ch1/`, `nutag/` хавтсаас ачаалагддаг. Тиймээс тэр repo-д эдгээр хавтас байх ёстой.

Жинхэнэ бүртгэлтэйгээр ашиглах: https://amyrln.github.io/Khaldun/
